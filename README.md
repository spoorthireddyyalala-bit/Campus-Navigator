# 🏫 Campus Navigator

Campus Navigator is a simple website designed to help students and visitors easily explore and find important locations inside a college campus.

This project is created using Bhoj Reddy Engineering College as a reference and provides information about different blocks, departments, and facilities in a simple and organized way.

## ✨ Features

- 🏠 Home page with an introduction to the project
- 🗺️ Campus Map section to understand different blocks
- 🏢 Department section with department locations
- 📚 Facilities section for important campus facilities
- 📞 Contact section for basic information

## 🛠️ Technologies Used

- HTML
- CSS

## 🎯 About the Project

The idea behind this project is to create a digital campus guide that helps new students and visitors quickly find important places without confusion.

It is a beginner-friendly web project created to practice HTML and CSS concepts while solving a real-world problem.
